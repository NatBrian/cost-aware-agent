# Category 2 Contrast Table: Agent Stopping, Early Exit & Adaptive Termination

| Paper | Our Motivation (cost-aware stopping) | Our Approach (monitor agent as reward model) | Our Solution (learned soft stopping curve) | Key Difference |
|-------|--------------------------------------|----------------------------------------------|-------------------------------------------|----------------|
| **CaRT** | Directly trains termination behavior — the closest prior work to our goal. | Trains the **same model** to both reason AND terminate (self-termination), not a separate monitor. | Binary termination decisions (terminate/continue) — no cost-awareness, no soft curve. | CaRT uses SFT on counterfactuals; we use a separate RL-trained monitor agent as a reward model. |
| **Dynamic Early Exit** | Detects reasoning convergence using token probability signals — similar to what our monitor would observe. | Uses fixed statistical thresholds (entropy, max probability) — no learned model, no reward signals. | Binary exit decision based on a fixed threshold — not a learned function of reasoning quality. | Statistical thresholds vs. learned monitor; our approach adapts to problem difficulty and model family. |
| **Diminishing Returns Early-Exit** | Shows that confidence-based exit criteria are poorly calibrated — reinforces need for learned stopping. | Evaluation only — no new method, no monitor, no training. | N/A — evaluation paper showing that existing exit criteria are unreliable. | Diagnostic paper establishing the problem our monitor solves. |
| **s1 (Budget Forcing)** | Budget forcing is the closest inference-time mechanism to cost-aware stopping. | Hardcoded interventions ("Wait"/truncate) — no model, no training, no reward signals. | Hard maximum/minimum token budgets — not a learned function of reasoning quality. | Hardcoded interventions vs. learned monitor; our approach is dynamic and context-aware. |
| **Budget Forcing + RL** | Shows that RL improves token efficiency of budget forcing — strong support for our training approach. | RL is embedded in the policy model itself with an accuracy reward — no separate monitor. | Static token budgets with RL-trained efficiency — no dynamic, per-instance stopping curve. | Efficiency is trained into the policy; our monitor is a separate component providing process-level signals. |
| **Don't Overthink It** | Validates that shorter chains are often better — empirical foundation for the value of stopping. | Inference-time early stopping based on chain length (shortest first) — no learned model. | Length-based selection (shortest chain wins) — not a learned cost-benefit trade-off. | Simple heuristic based on length; our monitor uses learned quality signals. |
| **Over-Reasoning** | Earliest demonstration of the over-reasoning problem — directly motivates our work. | Evaluation only — no proposed method, no monitor, no training. | N/A — diagnostic paper showing LLMs cannot recognize when reasoning is unnecessary. | Foundational problem statement paper; our work provides the solution. |
| **When More is Less** | Strongest theoretical/empirical evidence for optimal stopping — "inverted U-shaped" accuracy curve. | Observational/theoretical analysis — no method, no monitor, no training. | Proves optimal length exists but doesn't provide a way to find it dynamically. | Proves the problem exists; our monitor provides the solution. |

**Summary:** This category establishes **why** stopping matters — over-reasoning, diminishing returns, and inverted U-shaped accuracy curves. CaRT and s1 provide initial methods for stopping, but use simple heuristics (counterfactual SFT, hard budget forcing, chain length). None provides a learned, cost-aware, dynamic stopping mechanism. Our monitor agent fills this gap by learning to detect the optimal stopping point from reasoning quality signals rather than relying on fixed thresholds or chain length.
